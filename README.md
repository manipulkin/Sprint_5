# Sprint_5
# Проект с автотестами для сервиса Stellar Burgers (космический фастфуд).  
Тесты написаны на Python + Selenium 

## Структура
conftest.py – фикстура драйвера (открытие и закрытие браузера)

generators.py – генераторы случайных email, пароля, имени

locators.py –  локаторы элементов страниц

tests/ – тесты, сгруппированные по функциональности
